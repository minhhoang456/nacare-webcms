Hướng dẫn sử dụng Thanh toán dịch vụ online bằng mã code trên website hoặc ứng dụng của nhãn hàng
  • Bước 1: Chọn voucher ưu đãi muốn sử dụng, ấn "Sử dụng ngay" đđể xem chi tiết mã Code giảm giá
  • Bước 2: Chọn Sao chép mã khuyến mại.
  • Bước 3: Dán mã tại trang thanh toán trên website hoặc ứng dụng của nhãn hàng/thương hiệu để áp dụng ưu đãi.
